# mcam

複数の動画・音声ファイルの位置を **目と耳で** 合わせて、**全部が重なる範囲だけ** を無劣化で切り出すツールです。

- 動画 → `-map 0:V:0 -c:v copy -an`
- 音声 → `-map 0:a -c:a copy`

依存は `ffmpeg` / `ffprobe` と Python 3.8 以上（標準ライブラリだけ）。UI は手元のブラウザで開きます。

## 使い方

```bash
python3 mcam.py camA.mp4 camB.mov zoom.wav
```

`camA.mcam.json`（プロジェクト）が先頭ファイルの隣にでき、ブラウザで UI が開きます。位置は自動で保存されます。続きから開くときはこうします：

```bash
python3 mcam.py -p camA.mcam.json
```

UI を開かずに書き出しだけ行う場合：

```bash
python3 mcam.py export camA.mcam.json -o out/
```

### 合わせ方

1. 波形をドラッグして大まかに合わせる（`Shift` を押しながらだと 1/10 の速さで動きます）
2. 拍手やカチンコなど目印になる所で `Alt`+クリック（またはダブルクリック）してマーカーを置き、基準トラックを選んで `A` を押すと、全マーカーが揃う
3. 再生して耳で詰める。`L` で再生ヘッドの前後 1 秒をループ再生。選択トラックは `,` `.` で ±1 ms、`<` `>` で ±10 ms、`[` `]` で ±1 フレームずつ動きます。二重に聞こえる（フランジャーっぽくなる）のが消えれば合っています
4. 映像は止めた状態で `←` `→` を押すと 1 フレームずつ進んで、目で確認できます
5. 「書き出し…」を押す

| キー | 動作 |
|---|---|
| `Space` | 再生 / 停止 |
| `←` `→` | 1 フレーム移動（`Shift` で 1 秒） |
| `↑` `↓` | 選択するトラックを切り替え |
| `,` `.` / `<` `>` / `[` `]` | 選択トラックを ±1 ms / ±10 ms / ±1 フレーム動かす |
| `M` | 再生ヘッドの位置にマーカーを置く |
| `A` | 選択トラックのマーカーに、他のトラックのマーカーを揃える |
| `L` | ループ再生 |
| `Z` / `X` | 全体を表示 / 重なり部分を表示 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 取り消し / やり直し |
| ホイール | ズーム（`Shift` を押しながらで横スクロール） |

### 試聴の仕組み

- **音声** は書き出しと同じ ffmpeg でサーバ側で切り出し、Web Audio でサンプル単位のタイミングに予約して鳴らします。トラック同士の音の同期はサンプル単位で正確です
- **映像** は 360p のプレビュー（`.mcam-cache/` に作成）を音声のクロックに追従させて表示します。再生中は数十 ms 程度の揺れがありますが、止めた状態でのフレーム送りなら正確です。ブラウザで再生できる元動画なら、`--no-proxy` を付けるとプレビューを作らずに元ファイルをそのまま使います

## 書き出しと「実測」

`-c copy` で切るとき、どこで切れるかは形式によって違います。そこで書き出したあとに出力ファイルを元ファイルと照合して、**実際にどこから始まったか** を測り、`synced/sync_report.json` とログに残しています。

| 形式 | `-c copy` で切ったときの先頭 |
|---|---|
| MP4 / MOV の動画 | エディットリストのおかげで正確（ずれは 1 フレーム未満の刻みだけ）|
| MKV / MTS などの動画 | **キーフレームまで戻って** 始まる（GOP 長ぶんずれることがあります）→ `--video-ext mov` |
| WAV（PCM） | サンプル単位で正確 |
| AAC (m4a) / MP3 | サンプル単位で正確（エンコーダ遅延の情報で調整されます）|
| FLAC / ALAC | **フレーム境界** で始まる（数十 ms ずれます）→ `--lossless-reencode` |

ずれていた場合はログにこう表示されます：

```
実測: 先頭が理想より -1871.0 ms（-56.70 フレーム）← キーフレームまで戻って切れています。--video-ext mov / mp4 で…
```

### 注意

- エディットリストを無視する編集ソフトでは、MP4/MOV の切り出しもキーフレームから始まって見えます。そのときは `sync_report.json` の値を使って、ソフト側で調整してください
- 映像の「1 フレーム未満の刻み」は避けられません。ffmpeg の解釈では「指定時刻以降で最初のフレーム」が先頭になるので、カメラ同士で最大 1 フレーム弱ずれます（音声はずれません）
- 書き出す長さ（`-t`）の終わりは、パケット境界まで多少伸び縮みします

## オプション

```
python3 mcam.py FILES... [-p PROJECT] [--port 8765] [--no-proxy] [--no-browser]
                         [-o OUTDIR] [--video-ext EXT] [--lossless-reencode] [--no-verify]
python3 mcam.py export PROJECT [-o OUTDIR] [--video-ext EXT] [--lossless-reencode] [--no-verify]
```

- `--video-ext mov` … 動画の出力コンテナを変えます（MKV や MTS を正確に切りたいときに）
- `--lossless-reencode` … FLAC/ALAC などは同じコーデックで作り直します。音の中身は変わりませんが、`copy` ではなくなります
- `--no-verify` … 書き出し後の照合を省きます（長いファイルでも照合は数秒程度です）
- 環境変数 `MCAM_FFMPEG` / `MCAM_FFPROBE` で ffmpeg の場所を指定できます

## プロジェクトファイル

```json
{
  "version": 1,
  "out_dir": "synced",
  "tracks": [
    {"path": "/abs/camA.mp4", "offset": 0.0, "marker": 12.34, "gain": 1.0, "mute": false},
    {"path": "/abs/zoom.wav", "offset": 3.1234, "marker": null, "gain": 1.0, "mute": false}
  ]
}
```

`offset` は「そのファイルの 0 秒が、タイムライン上の何秒にあるか」を表します。ファイルの 0 秒は、ffprobe の `format.start_time` を基準にしています。
